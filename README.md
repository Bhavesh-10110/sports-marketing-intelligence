# 🏏 Sports Marketing Intelligence Using Machine Learning

## 📌 Project Overview

Sports Marketing Intelligence is a Machine Learning-based analytics system designed to help cricket kit brands identify high-value IPL audiences and predict potential cricket kit buyers.

The project analyzes:
- Customer demographics
- IPL engagement behavior
- Sports content consumption
- Purchase behavior

Using Machine Learning techniques, the system performs:
- Customer Segmentation
- Purchase Prediction
- Marketing Intelligence Generation

---

# 🚀 Features

✅ Customer Segmentation using K-Means Clustering  
✅ Cricket Kit Purchase Prediction using Random Forest  
✅ IPL Audience Analysis  
✅ Feature Engineering  
✅ Exploratory Data Analysis (EDA)  
✅ React Frontend + FastAPI Backend  
✅ End-to-End ML Pipeline  

---

# 🧠 Machine Learning Models Used

## 1. K-Means Clustering
Used for:
- Customer Segmentation
- Audience Grouping
- Behavioral Analysis

Generated customer groups such as:
- Premium Hardcore IPL Fans
- Budget IPL Enthusiasts
- High Income Casual Viewers
- Low Engagement Users
